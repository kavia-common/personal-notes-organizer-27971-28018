# personal-notes-organizer-27971-28018

This workspace contains the Notes App Frontend (React Native / Expo) with Ocean Professional theme.

- Theme colors:
  - primary: #2563EB
  - secondary/success: #F59E0B
  - error: #EF4444
  - background: #f9fafb
  - surface: #ffffff
  - text: #111827

To run the mobile frontend in this container:
- cd notes_app_frontend
- npm install
- npm run web (uses the existing preview system on port 3000)

Features implemented:
- CRUD for notes
- Search by title/content
- Category management and filtering
- SQLite with AsyncStorage fallback
- Ocean Professional theme components (AppBar, Button, TextField, Card, Chip, FAB, EmptyState)
